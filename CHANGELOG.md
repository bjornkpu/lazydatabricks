## [0.1.0] - 2026-09-07

First release. Terminal UI over the Databricks REST API: jobs, runs, pipelines and SQL
warehouses across several workspace profiles, with authentication delegated to the Databricks
CLI. Read-only unless started with `--allow-actions`.
